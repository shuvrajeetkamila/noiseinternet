Do you need them?
----------------
No, not for the NoiseInternet.exe in this zip. That binary is linked with /MT (static runtime), so the C++
runtime is inside it. They are included so that a build configured with -DNI_STATIC_RUNTIME=OFF - which
links /MD and therefore imports exactly these three DLLs - can be run by copying them next to the exe
instead of installing the redistributable system-wide. The exe's own status screen prints which of the two
it is, and BUILD-INFO.txt records what dumpbin saw in the import table of this specific file.
